# Matchday 3D

An original, browser-based 3D football game. Open `index.html` in a modern desktop browser. It uses the Three.js browser module hosted on jsDelivr, so the first launch needs an internet connection.

## Play

1. Choose a club, opponent, match length, and difficulty.
2. Select **Kick Off**.
3. Use the keyboard controls shown on-screen:

| Key | Action |
|---|---|
| `W A S D` or arrow keys | Move the selected player |
| `Shift` | Sprint |
| `J` | Short pass |
| `L` | Long pass |
| Hold, then release `K` | Shoot — holding longer adds power |
| `Q` | Switch player |
| `Space` | Standing tackle |
| `E` | Slide tackle |
| `Esc` | Pause |

The game includes 10 selectable clubs, full 11-player squads, a TV camera, AI opponents on two difficulty levels, goalkeepers, passing, shooting, set pieces, simplified offsides, fouls, match clock/halftime/full-time, and a final stats screen.

For the most reliable local launch, serve this folder with any static-file server, then open the served URL in Chrome, Edge, Firefox, or Safari.
